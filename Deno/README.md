# AutoPtT - Deno version


Run with:

```
deno run --allow-ffi --allow-read --allow-write --allow-env autoptt.js <command>
```


Run remotely (no file on disk):

```
deno run --allow-ffi --allow-read --allow-write --allow-env https://raw.githubusercontent.com/ricardojoserf/AutoPtT/main/Deno/autoptt.js <command>
```
